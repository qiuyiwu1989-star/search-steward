# 002：统一执行与发布基础

## 要什么
在独立仓库实现 S01—S04 的最小闭环：持久化提交队列、版本化公开清单、问题聚合、离线发布闸门。先完成可审阅代码与迁移预案，原后台生产切换单独确认。

## 不做什么
不新增定时任务；不修改原生产模块/队列/数据库；不自动创建第三方账号；不自动发布正文；不绕过 TLS；不默认发送 HTTP 凭据。

## 验收
- 队列同域 URL/版本幂等，跨域不改写；并发不能重复取件。
- 请求结果不明确进入 unknown，不自动重发；可凭依据人工重排或确认。
- 成功回执可幂等写入管家，失败和额度耗尽保留。
- 清单 schema 版本、身份、路径、授权和发布状态检查。
- 聚合同类发现，保留各页面和既有整改状态，不自动关闭。
- 发布前只检查显式清单；空正文、敏感来源、错误 canonical、noindex 和坏 JSON-LD 阻断。
- 通过离线测试，不使用真实配额；生产迁移预案含备份、去重、回滚。
